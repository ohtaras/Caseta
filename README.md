# caseta

Ο κατάλογος της καφετέριας caseta σε μορφή ιστοσελίδας.

Για αλλαγές τιμών: άνοιξε το `index.html` και άλλαξε την τιμή δίπλα στο προϊόν.

## Αρχεία εκτύπωσης (φάκελος `print/`)

- `caseta-katalogos.pdf`: ο έντυπος κατάλογος, 13 σελίδες, 216×303 mm (A4 με 3 mm bleed σε κάθε πλευρά).
- `caseta-qr.png` / `caseta-qr.svg`: QR code με το λογότυπο, οδηγεί στο https://ohtaras.github.io/Caseta/
